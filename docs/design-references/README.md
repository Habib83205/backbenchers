## BACKBENCHERS design brief

- **Setting:** Realistic school classroom; iconic wooden arena **Table No. 21**.
- **Rendering:** Layered, naturalistic 2.5D presentation over consistent 2D pen physics.
- **Mood:** Warm daylight, aged wooden school bench, classroom ambience, school-life nostalgia.
- **Gameplay readability:** Pen silhouettes, collision space, desk perimeter and fall state must remain clearly visible.
- **UI:** Modern polished game UI inspired by school notebooks; tactility without excessive cartoon graphics.
- **Menus:** Home lobby, game modes, pen collection, arena selection, match HUD, progression, quests, settings.
- **Responsive:** Desktop mouse and mobile touch; scalable labels and reachable controls.
- **Motion:** Smooth polished transitions, hit feedback, reduced-motion option, no distracting effects over playfield.
- **Scope:** Integrate only relevant inspiration. Do not reproduce any reference screen 1:1.
