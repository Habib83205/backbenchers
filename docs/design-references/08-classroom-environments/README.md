## BACKBENCHERS environmental art brief

- **First arena:** Table No. 21 — one believable old wooden classroom bench.
- **Physics:** One stable 2D desktop play plane with readable boundaries and reliable pen falling/collisions.
- **Presentation:** Layered realistic 2.5D classroom depth, gently angled overhead camera and soft parallax.
- **Lighting:** Warm late-afternoon sunlight, contact shadows, mild ambient dust; focus stays on the pens.
- **Background details:** Chalkboard, surrounding benches, school windows, clock and occasional posters; avoid clutter around the active playfield.
- **Aesthetic:** Nostalgic yet premium, naturally realistic rather than exaggerated cartoon.
- **Performance:** Mobile-friendly optimizations and accessible desktop/touch controls.
- **UI references:** See [the parent design reference catalog](../README.md); classroom screenshots are environment inspiration, not UI layouts.
- **Originality:** Do not ship/reference images as final background textures or recreate copyrighted illustrations, branding, or complete scenes verbatim. Create original properly licensed assets.

The referenced PNGs belong in this folder alongside this guide; they are design inputs, **not runtime game assets**.
