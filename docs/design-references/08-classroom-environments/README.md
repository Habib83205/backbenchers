## Creative direction

- **Gameplay:** Place both pens on a single realistic wooden school bench; stable physics plane, legible play area and visible desk edges.
- **Perspective:** 2.5D near top-down / gently angled classroom desk. The rest of the classroom is secondary context, with natural depth and selective defocus.
- **Atmosphere:** Late-afternoon golden sunlight, green chalkboard, aged wooden bench texture, believable school furniture, light natural dust and scratches.
- **Authenticity:** The initial arena, **Table No. 21**, should evoke lived-in school nostalgia rather than a sterile classroom or cartoony toy room.
- **Performance:** Optimize visual layers for mobile; keep lighting achievable with image layers, shaders or baked effects without requiring full 3D world simulation.
- **Gameplay clarity:** Never let notebooks, chairs, reflections, HUD panels or props obscure pen collisions and drop-off edges.
- **UI vs environment:** These are *environment* examples, not UI layouts. Use [`../README.md`](../README.md) and earlier reference categories for game UI design.
- **IP:** References are for internal inspiration only; do not copy watermarked branding, embedded artwork, existing characters, or an entire layout. Produce original, properly licensed final assets.

**Reference files are not runtime assets.** Do not import these screenshots into the shipped gameplay build unchanged.
